# Ankit - Task 29
## Shoe Store Payment System

### Project Description
This is a simple shoe shopping website developed using React and Vite.
It uses React Context API to manage the shopping cart.

### Features
- Display shoes with images and prices
- Add shoes to the shopping cart
- Remove items from the cart
- Calculate the total price
- Navigate to the payment page
- Enter card details in the payment form
- Demo payment success message
- Cash on Delivery option
- Return to the shopping page

### Technologies Used
- HTML
- CSS
- JavaScript
- React.js
- React Context API
- Vite

### How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL shown in the terminal.

### Note
This is a demonstration project. It does not process real payments.
